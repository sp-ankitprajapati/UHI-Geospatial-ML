# CV wording aur honest project story

## Suggested title

Hyderabad Landsat Surface-Temperature Analysis | Python, NumPy, Pandas, Rasterio/GDAL, GeoPandas, scikit-learn, QGIS, pytest

## Suggested bullets

- Built a reproducible two-scene Landsat 8 pipeline with QA masking, common-grid alignment and paired surface-temperature summaries across 145 supplied Hyderabad ward features.
- Evaluated land-cover Random Forests using five-fold spatial blocks and 300 m buffers, exposing optimistic random-split scores and documenting class-coverage limitations.
- Added checksum-verified data retrieval, model/split metadata, reproducible evidence and 21 automated tests covering physical scaling, NoData, raster alignment and paired aggregation.

Optional quantitative observation, only if space and explanation allow:

- Measured a +7.40 °C mean LST difference across 591,749 paired clear pixels between 23 May 2016 and 24 May 2022, explicitly scoped to the selected observations.

“Original version mein QGIS processing aur random-split notebook the. Upgrade mein maine data provenance, common features, QA handling, coordinate alignment aur spatial testing add/verify ki. Random split 100% tha, lekin new locations par score poor mila. Maine weak model outputs ko experimental label kiya aur training sampling ko next improvement identify kiya. Direct Landsat temperature calculation model se separate hai.”
